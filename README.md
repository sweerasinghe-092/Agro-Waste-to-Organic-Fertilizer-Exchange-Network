Agro Waste to Organic Fertilizer Exchange Network

1. Project Description

The Agro Waste to Organic Fertilizer Exchange Network is a web-based platform that connects agricultural waste providers with individuals and organizations who need agricultural waste for organic fertilizer production.

The system aims to make agricultural waste exchange easier and encourage the reuse of agricultural waste for sustainable fertilizer production.

2. Project Objectives

- To connect agricultural waste providers with potential users.
- To provide an online platform for listing available agricultural waste.
- To make searching and viewing agro waste materials easier.
- To promote the reuse of agricultural waste.
- To reduce agricultural waste disposal and environmental pollution.
- To encourage sustainable agricultural practices.

3. Technologies Used

- PHP
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP
- Visual Studio Code
- Git and GitHub

4. Main Features

- User Registration and Login
- Role-Based User Management
- Agro Waste Listing Management
- Search and View Agro Waste Details
- Provider Information
- User-Friendly Interface

Note: Features will be developed and improved throughout the project.

6. Version Control and Collaboration

GitHub is used for version control and team collaboration.

Each team member works on their assigned tasks using separate branches. Code changes are regularly committed, pushed, reviewed, and merged into the main branch.
